# Скилл: Диагностика и автоисцеление мигания Killswitch

Этот скилл полностью опирается на автоматизированное системное действие **`actions.killswitch_heal`** из пакета `actions` программы `herdrCenter`.

---

## 1. Автоматический запуск исцеления (в 1 команду)

При обнаружении мигания соединения или дребезга сокета запустите из директории `C:\MyFiles\herdrCenter`:

```powershell
.\.venv\Scripts\python.exe -m actions killswitch_heal --port 1015
```

### Флаги и опции:
* `--port <PORT>`: Порт целевого сокета (по умолчанию `1015`).
* `--dry-run`: Анализ состояния и поиск конфликтов без закрытия процессов и удаления файлов.
* `--verbose`: Подробный вывод журнала сканирования процессов и замеров.
* `--json`: Вывод структурированных результатов для автоматической обработки агентами.

---

## 2. Что делает действие под капотом

1. **Аудит владельца сокета (`inspect_port_owner`):**
   - Вызывает `Get-NetTCPConnection` и связывает сокет с процессами Windows (`PID`, `Name`, `ParentPID`, `CommandLine`).
   - Идентифицирует, кто реально держит порт: штатный инстанс или чужой супервизор.

2. **Очистка устаревших общих конфигов (`clean_legacy_configs`):**
   - Удаляет несегментированный файл `C:\MyFiles\vless2socks\runtime\xray-config.json`, который провоцировал запуск `xray.exe` с чужим портом `1015` при падении соседних инстансов (`1081..1085`).

3. **Обнаружение дребезга и ликвидация зомби (`kill_rogue_processes`):**
   - Проводит экспресс-серию замеров сокета.
   - Если зафиксировано чередование `True` и `False` (дребезг), принудительно завершает конфликтующие процессы `xray.exe` и осиротевшие супервизоры.

4. **Сброс кэша изоляции (`reset_isolation_cache`):**
   - Сбрасывает глобальную переменную `_LAST_APPLIED_ISOLATION_KEY` в `node_isolate_manager.py` для синхронизации состояния сетевого экрана WSL2 с реальным статусом сокета.

5. **Контрольный замер стабильности (`verify_flapping_stability`):**
   - Фиксирует 5 контрольных замеров состояния с интервалом 0.3 секунды.
   - Подтверждает абсолютную монотонность состояния (`stable=True`).

---

## 3. Чек-лист стабильности после применения

Для проверки общего сетевого здоровья выполните:

```powershell
.\.venv\Scripts\python.exe -m actions verify_connectivity --port 1015
```
