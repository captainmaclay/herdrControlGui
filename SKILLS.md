# Herdr AI Skills Integration Guide

В проекте **Herdr** активная настройка баз данных и провайдеров больше не выполняется "жестко" (hardcoded) кнопками из GUI. Вся оркестрация и применение конфигураций делегирована **интеллектуальным агентам (LLM)**. 

Это руководство описывает скиллы (Skills) и инструкции, как ИИ-модель должна настраивать интеграции `AionUi`, `Claude Code` и `OmniRoute (Gemini)`.

---

## Skill 1: Авто-настройка OmniRoute Gemini Farm

### Описание:
Агенты должны использовать этот чек-лист для прозрачной настройки кластера бесплатных аккаунтов Gemini в локальном балансировщике. Роутер переключает сессии при получении триггера `429 (Resource exhausted)`.

### Действия, требуемые от ИИ-Агента:
1. **Проверить SOCKS-сокеты Herdr:**
   Опросить локальные сокеты TCP начиная с `1081`. 
   Аккаунты Gemini Farm маппятся строго последовательно: 
   - `account-1` -> 127.0.0.1:1081
   - `account-2` -> 127.0.0.1:1082
2. **Зарегистрировать Провайдера в AionUi:**
   Вместо того чтобы изменять `aionui-backend.db` с помощью Python-скрипта GUI, Агент должен использовать свои *встроенные Tools (например aionui-config / sqlite-exec)*, чтобы добавить провайдера:
   ```sql
   INSERT OR REPLACE INTO providers (id, platform, name, base_url, models, enabled)
   VALUES ('custom_gemini_farm', 'custom', 'OmniRoute Gemini Farm', 'http://127.0.0.1:20128/v1', '["gemini-farm"]', 1)
   ```
3. **Обновить конфигурацию OmniRoute:**
   Вписать обнаруженные порты SOCKS в массив роутинга OmniRoute (`routes.config.json` или аналог в вашей системе), чтобы он знал, на каких портах сидят живые профили.

## Skill 2: Авто-настройка Claude SOCKS5 Anti-Fraud

### Описание:
Claude (Anthropic) банит аккаунты за резкую смену ASN или IP. Агент, интегрирующий Claude Code в AionUi, должен жестко закрепить весь трафик за SOCKS-прокси `1015`.

### Действия, требуемые от ИИ-Агента:
1. **Диагностика SOCKS:**
   Убедитесь, что `127.0.0.1:1015` слушает трафик. Это выделенный SOCKS-канал Claude.
2. **Глобальный Killswitch:**
   Используя `aionui-config`, измените настройки агентов в `settings.json` или `agent_metadata`, внедрив переменные окружения:
   ```json
   {
       "HTTP_PROXY": "socks5h://127.0.0.1:1015",
       "HTTPS_PROXY": "socks5h://127.0.0.1:1015",
       "ALL_PROXY": "socks5h://127.0.0.1:1015"
   }
   ```
   **Важно:** ИИ должен убедиться, что если таргет `1015` падает, AionUi обрывает связь, а не переключается на прямой сетевой интерфейс! Это называется политика *Killswitch* (блокировка прямого трафика).
3. **Обновление бинарников (Manifest):**
   Если требуется, Агент должен скачать нужный патч-бинарник `claude 2.1.280`, перезаписать его в директории `managed/resources/` и обновить `manifest.json`.

---

## Инструкция для вызова (Triggering):
Пользователь может просто написать агенту: *"Агент, настрой интеграцию с Claude по скиллам"*, и агент должен прочитать этот файл (`SKILLS.md`), проверить порты (через Python или bash-tools) и выполнить все настройки окружения (`aionui-config`) самостоятельно.
