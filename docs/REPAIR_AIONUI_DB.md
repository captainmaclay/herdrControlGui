# Руководство: Автоматическое восстановление базы данных и чатов AionUi (WSL2)

## Симптомы проблемы
- В веб-интерфейсе AionUi (`http://localhost:25808`) внезапно исчезли чаты или отображается **«No chat history»**.
- При клике на существующий чат появляется ошибка: **«Conversation not found»** (HTTP 404).
- При отправке сообщений появляется ошибка: **«Internal server error»** (HTTP 500).
- В логах `~/.aionui-web/logs/.../aioncore.log` появляются строки:
  ```text
  (code: 11) database disk image is malformed
  Tree 8 page ...: btreeInitPage() returns error code 11
  database is locked
  ```

---

## Быстрое решение в 1 клик

В корне репозитория `herdrControlGui` создан готовый сценарий:

### Способ 1: Из Windows (батником)
Просто запустите дважды кликнув:
```text
D:\My files\herdrControlGui\repair_aionui.bat
```

### Способ 2: Из консоли WSL / Bash
```bash
python3 /mnt/d/My\ files/herdrControlGui/scripts/repair_aionui_db.py
```

Скрипт автоматически:
1. Останавливает фоновые процессы `aioncore` и `aionui-web`.
2. Создает резервную копию базы перед починкой в `~/.aionui-web/db_backups/`.
3. Сбрасывает и синхронизирует WAL-журнал (`wal_checkpoint(TRUNCATE)`).
4. Переносит все 33 таблицы и сообщения в новую чистую базу без битых секторов.
5. Пересоздает B-Tree индексы заново.
6. Выполняет `PRAGMA integrity_check` (гарантирует `[('ok',)]`).
7. Удаляет подвисшие lock-файлы (`.instance.lock`, `.migrate.lock`, `-wal`, `-shm`).
8. Перезапускает AionUi в tmux на порту 25808 и проверяет доступность API.

---

## Почему эта поломка возникает?

1. **Кросс-файловая синхронизация WSL2 (9P / SMB)**: Когда Windows-процессы обращаются к диску WSL (например, сканирование антивируса, поиск Windows Search или прямое чтение `.db` файлов по сети `\\wsl$\...`) во время того, как `aioncore` пишет транзакции в WAL-режим, файловые блокировки Windows не согласуются с блокировками Linux ext4, что может вызывать повреждение страниц (torn writes).
2. **Гигантские фрагменты текста в логах**: Когда агент в чате читает файлы по 100–300 КБ или выводит большие логи, таблица `messages` создает сотни страниц переполнения (overflow pages).
3. **Зависшие файлы блокировки**: Наличие `.instance.lock` и `.migrate.lock` блокирует миграции.

## Зарегистрированный скилл для ИИ-Агента (Antigravity)

Скилл зарегистрирован глобально и локально в проекте:
- Глобальный: `~/.gemini/config/skills/repair-aionui-db/SKILL.md`
- В проекте: `.agents/skills/repair-aionui-db/SKILL.md`

В будущем любой ИИ-помощник при фразе пользователя **«почини базу AionUi»** или **«пропали чаты в AionUi»** автоматически активирует этот скилл и восстановит данные за 8 секунд.
