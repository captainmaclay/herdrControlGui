# Herdr Token Integration Guide (AionUi & OmniRoute)

Этот документ предназначен для систем и нейросетей, разрабатывающих интеграцию ИИ-симуляторов (таких как AionUi) и прокси-роутеров (OmniRoute) с ядром Herdr. 

Архитектура Herdr выстроена вокруг максимальной безопасности аккаунтов. **99% времени токены хранятся на жестком диске в зашифрованном виде**. Интегрируемые сервисы должны учитывать механизм `Token Vault` (Хранилище токенов) и правильно с ним взаимодействовать.

## 1. Шифрование и Token Vault (Декодирование "на лету")

Все конфиденциальные токены (Claude OAuth `config.json`, `.credentials.json` и Gemini `antigravity-oauth-token`) шифруются по стандарту:
* **Алгоритм:** `AES-256-GCM` 
* **Деривация ключа:** `PBKDF2-HMAC-SHA256` (соль 16 байт)
* **Структура зашифрованного файла (`.enc`):** `Соль (16 байт) + Nonce/IV (12 байт) + Шифротекст с GCM-тегом`
* **Дополнительные данные (AAD):** `HRDRTK01`
* **Мастер-ключ (Пароль):** берется из системного файла `.env` в корневой директории Herdr.

### Поведение интеграции OmniRoute / AionUi
Так как OmniRoute является балансировщиком и работает в фоне, у интеграций есть два пути взаимодействия с токенами:

**Путь А (Векторный вызов дешифровки перед стартом)**
OmniRoute не должен пытаться дешифровать файлы самостоятельно. На стороне `herdrControlGui` реализован CLI и модули:
1. При старте активной сессии OmniRoute (или скриптом AionUi), вызывается команда разблокировки: 
   `python3 token_vault_manager.py --unlock <пароль_из_.env>`
2. Токены материализуются на диске в виде обычных JSON-файлов в папках `~/.claude/` и `~/.gemini/profiles/`.
3. OmniRoute/AionUi начинает работу.
4. После остановки балансировщика, вызывается:
   `python3 token_vault_manager.py --lock <пароль>`

**Путь Б (Автоматическая разблокировка через Интегратор GUI)**
В `integrations_manager.py` уже встроена логика: если пользователь нажал «Синхронизировать», скрипт сам подставит пароль из `.env`, временно расшифрует токены и передаст в базу данных чистые сессионные данные.

## 2. Интеграция с Gemini Farm (OmniRoute)

Важно понимать, что бесплатные лимиты Google Gemini (Free tier) жестко ограничены по контексту (TPD / RPD).
OmniRoute должен реализовывать **мгновенный Round-Robin (карусель) с отвязкой сессий (session un-stickiness)**.

* **Алгоритм перехвата (Circuit Breaker):** На каждый запрос к `gemini-farm` роутер должен слушать ответы от Google API.
* **Триггер ошибки 429:** Если Google возвращает статус `429` с текстом `"Resource has been exhausted (e.g. check quota)."`, этот профиль должен быть мгновенно помечен как `quota_exhausted`.
* **Переключение (Failover):** Текущий аккаунт замораживается на длительный срок (до 24 часов), и OmniRoute должен разорвать липкость. Следующий запрос внутри *того же самого диалога* должен быть направлен уже на `account-2` (SOCKS порт 1082) в прозрачном режиме, чтобы пользователь не получил отказ в обслуживании.
* Регулярное выражение (RegEx) для триггера `429` обязано включать строку: `/resource has been exhausted \(e\.g\. check quota\)/i` (так как Gemini не отдает строку `reset after`).

## 3. Интеграция Claude Code (Системные SOCKS)

Anthropic имеет невероятно агрессивный антифрод. Любое расхождение в отпечатках TLS или смена IP-адресов при переносе токенов ведет к немедленному бану (shadowban).

**Требования для интеграции модулей AionUi:**
1. AionUi (вызывающий Claude-клиент) **ни при каких обстоятельствах не должен обращаться к API Anthropic напрямую**. 
2. Все сетевые запросы `claude ...` должны пробрасываться строго через локальный SOCKS5, который привязан к текущему токену. По умолчанию это `127.0.0.1:1015` для базового аккаунта.
3. Интеграция должна нативно транслировать `HTTP_PROXY`, `HTTPS_PROXY` и `ALL_PROXY='socks5h://127.0.0.1:1015'` в окружение `wsl` перед запуском процесса агента, чтобы авторизационный поток и диалог происходили в точности с того IP, с которого был сгенерирован OAuth SessionKey.
